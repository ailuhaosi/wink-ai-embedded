# UniSim 已知仿真局限性（Known Simulation Limitations）

| 项 | Content |
|---|---|
| **文档类型** | 已知局限性说明 (Known Limitations) |
| **所属总纲** | [`00-master-execution-plan.md`](./00-master-execution-plan.md) |
| **状态** | **Living Document** — 随各阶段落地持续更新 |
| **核心用途** | 明确 WASM 仿真环境与真实 ESP32 硬件之间的已知行为差异，帮助用户正确设定仿真预期 |

> [!IMPORTANT]
> 本文档列出的"局限性"均属**有意为之的设计取舍**（而非 Bug），在仿真场景下以性能与可观测性优先，在真实硬件验证中以物理保真度优先。

---

## 1. 时序类局限性

| 编号 | 特性 | 真实 ESP32 硬件 | UniSim 仿真 | 受影响器件/场景 |
|---|---|---|---|---|
| T-1 | **NRZ 位时序精度** | 精确到纳秒级 RMT/UART 硬件时序 | 不仿真（以帧/字节为传输单元） | WS2812、DHT11、单总线传感器 |
| T-2 | **时钟抖动（Jitter）** | 存在 ±ns 级晶振/PLL 抖动 | 不仿真（虚拟时钟为确定性整数 μs） | 高精度时序测量、PulseIn 精度极限测试 |
| T-3 | **I2C/SPI 总线电容延迟** | 信号建立/保持时间受线路电容影响 | 不仿真（总线事务即时完成） | 高速 I2C（400kHz+）场景 |
| T-4 | **UART 波特率误差** | 实际波特率受分频误差影响（通常 <1%） | 不仿真（字节注入无速率限制） | 高精度波特率匹配测试 |
| T-5 | **PWM 死区（Dead Time）** | 互补 PWM 通道有硬件死区插入 | 不仿真（PWM 占空比直接传递） | H 桥电机驱动高精度死区配置 |

## 2. 电气类局限性

| 编号 | 特性 | 真实 ESP32 硬件 | UniSim 仿真 | 受影响器件/场景 |
|---|---|---|---|---|
| E-1 | **电源噪声对 ADC 的影响** | 存在（尤其 WiFi 发射时） | 可选（`fidelityLevel: "noisy"` 模式激活 ±3 LSB 噪声） | ADC 精度验证 |
| E-2 | **引脚驱动电流限制** | GPIO 最大拉/灌电流 ~40mA | 不仿真（引脚电平仅为逻辑值，无电流概念） | LED 限流电阻设计验证 |
| E-3 | **上拉/下拉电阻值影响** | 影响边沿速率与总线电平 | 不仿真（PinArbiter 仅处理逻辑驱动强度） | I2C 上拉电阻选型验证 |
| E-4 | **模拟信号串扰** | 相邻引脚间存在耦合电容串扰 | 不仿真 | 多通道 ADC 同步采样串扰测试 |

## 3. 系统类局限性

| 编号 | 特性 | 真实 ESP32 硬件 | UniSim 仿真 | 受影响器件/场景 |
|---|---|---|---|---|
| S-1 | **看门狗定时器（WDT）复位** | 死循环或长时间未喂狗触发复位 | 不仿真（仿真不会因此复位） | 看门狗超时检测/防死锁逻辑 |
| S-2 | **Flash 写入耗时** | 1~4ms/页（NVS 写入有明显延迟） | 不仿真（Flash 操作即时完成，0 延迟） | NVS 持久化写入耗时测试 |
| S-3 | **双核 SMP 并发** | ESP32 有两个独立 Xtensa 核心 | 不仿真（WASM 单线程，所有逻辑串行化） | SMP 多核并发竞争条件测试 |
| S-4 | **中断嵌套优先级** | 支持硬件中断嵌套（最多 7 级） | 简化为单级虚拟 IRQ 队列，不支持嵌套 | 高优先级中断抢占低优先级中断场景 |
| S-5 | **DMA 传输时序** | DMA 可在 CPU 运行时异步搬运数据 | 不仿真（DMA 传输在 C 侧同步完成） | SPI DMA 大块数据传输性能验证 |
| S-6 | **传感器预热/上电延迟** | 部分传感器（如 DHT11）需 1~2s 预热期 | 仅在 `fidelityLevel: "noisy"` 模式下仿真预热判定 | 传感器冷启动逻辑验证 |

---

## 4. 仿真精度等级对照

根据 `wink-app.json` 中的 `simulation.fidelityLevel` 配置，不同等级激活的仿真特性不同：

| 仿真特性 | `ideal` | `nominal` | `noisy` |
|---|:---:|:---:|:---:|
| ADC 高斯噪声 | ✗ | ±1 LSB | ±3 LSB |
| RC 低通滤波 | ✗ | ✓ | ✓ |
| 脉冲时序抖动 | ✗ | ±1 μs | ±5 μs |
| 传感器预热延迟 | ✗ | ✗ | ✓ |
| UART 字节速率限制 | ✗ | ✗ | ✗（暂不仿真）|

## 5. 维护约定

- **新器件接入时**：若该器件依赖本文档中已列出的局限特性（如 NRZ 时序），必须在器件的 Plugin 文档中注明"真实硬件与仿真行为差异"。
- **新局限性发现时**：在对应阶段 PR 中同步更新本文档，不得遗漏。
- **局限性消除时**（如未来支持了某项特性）：在对应行标注 `已落地` 并链接到落地 PR，而非直接删除记录。
